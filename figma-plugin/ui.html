✨ Let Claude do this screen

Use the normal Claude app (claude.ai or the desktop app) with your Claude subscription. You don't need Claude Code. Claude follows the same design rules as this plugin, but it can actually look at your screen, so it handles unusual designs better.

First time only · about 5 min

Give Claude the web-version rulebook
This file teaches Claude how to turn mobile screens into desktop ones. In Claude: Customize → Skills → + → Upload a skill → pick web-version.zip (in the claude-skill folder of this plugin's download).
